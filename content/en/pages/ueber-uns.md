## What motivates us

A clear map can make a good question visible. An open API can save someone else time. We volunteer to build these tools and make public information more useful.

## Open Data, Open Source and Civic Tech

Open data should be accessible on understandable terms. Open source allows people to inspect and improve software. Civic tech connects these possibilities with questions from civil society.

## History and network

The lab belongs to Code for Germany, initiated by Open Knowledge Foundation Deutschland. Regional questions have led to maps of playgrounds, schools and street trees. A dated history will follow once milestones have been documented.

## How we work

We start with a question, examine data and licences and work in small, understandable steps. Documentation and peer review are part of that process. Our [supporting association](/daten-sind-daten) provides an organisational framework. New perspectives from the border region are welcome.
