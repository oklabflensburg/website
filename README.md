# OK Lab Flensburg Website

Mehrsprachige Website des OK Lab Flensburg mit Fokus auf digitales Ehrenamt sowie GIS- und Datenbank-Contributor.

## Entwicklung

```bash
corepack enable
pnpm install
pnpm dev
```

Die Sprachen sind unter `/de`, `/da` und `/en` erreichbar. Die Startseite leitet auf Deutsch weiter.
